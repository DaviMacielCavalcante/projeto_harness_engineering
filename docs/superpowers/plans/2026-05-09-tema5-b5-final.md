# Tema 5 — RAG Distribuído
## Engenharia de Contexto e Harness Engineering aplicada à PDP
Equipe — Maio 2026

---

# Por que Tema 5?
- Combina paralelismo de **dados** (indexação) com paralelismo de **tarefas** (atendimento).
- Cache distribuído entra naturalmente.
- Engenharia de contexto explícita: chunking, re-ranking, function calling, sessão.

---

# Restrição: ambiente local
- Sem AWS Academy → 3 PCs reais via Tailscale (LAN privada virtual).
- Mapeamento dos serviços AWS para equivalentes locais (tabela).
- Bônus: SLM auto-hospedado (Ollama + experimento vLLM).

---

# Arquitetura (diagrama)
[diagrama macro]

---

# Pipeline de ingestão (paralelismo de dados)
- Duas filas: `ingest.documents` → `ingest.chunks`.
- Workers paralelos consomem chunks, embeddam via Ollama, escrevem no Qdrant.

---

# Pipeline de query (paralelismo de tarefas)
- Cache L1 (embedding) → retrieval → re-rank cross-encoder → cache L2 → generate.
- Function calling para citações estruturadas.
- Memória de sessão com sumarização adaptativa.

---

# Tolerância a falhas
- Retry com backoff (tenacity).
- DLX/DLQ no RabbitMQ.
- Fallback "degraded mode" no gateway.
- Healthchecks em todos os containers.

---

# IaC e deploy
- Terraform (provider docker) + Ansible.
- Modo 1 (single-host) para dev; Modo 2 (3 PCs Tailscale) para integração e demo.
- Mesma base de código nos dois modos.

---

# Observabilidade
- Prometheus + Grafana + Loki.
- Dashboard "RAG Distribuído" com 4 painéis.
- Logs estruturados (JSON) com `correlation_id`.

---

# Resultados — Exp 1: Speedup da indexação
[gráfico exp1.png]
- Speedup quase-linear até saturar Ollama.
- Eficiência ≥0.7 com ≤4 workers.

---

# Resultados — Exp 2: Throughput de queries
[gráfico exp2.png]
- p95 estável até C=8; latência sobe a partir daí.
- Throughput satura no gargalo de generation.

---

# Bônus — Exp 3: Ollama vs vLLM
[gráfico exp3.png se executado]
- vLLM: continuous batching → throughput até 2x maior em alta concorrência.
- Tese: paralelismo da aplicação só escala quando o servidor de inferência também batcha.

---

# Resultados — Exp 4: Tolerância a falhas
[gráfico exp4.png]
- Recuperação automática após kill de worker e Ollama.
- Fila drena após rajada; sem perda de mensagens (DLQ vazia).

---

# Limitações e melhorias futuras
- Sem hybrid search (BM25 + dense).
- Eval com 50 queries — pequena.
- Sem multi-tenancy.
- Próximo: índice incremental por hash, autenticação na API.

---

# Uso de IA
- Claude Code (Opus 4.7) como co-piloto: brainstorm, plano, boilerplate.
- Decisões de escopo, validação, integração e análise: humanos.
- Documentação completa em `docs/USO_DE_IA.md`.

## Estrutura

- `src/` — código de aplicação (gateway, workers, rerank-service, shared).
- `prompts/` — prompts versionados (engenharia de contexto explícita).
- `infra/` — Terraform, Ansible, Docker, configs Prometheus/Grafana/Loki.
- `tests/` — unit + integration.
- `scripts/` — smoke, seed, experimentos, plots, dlq inspector.
- `data/` — saídas dos experimentos (CSVs, gráficos).

## Pré-requisitos

- Docker + Docker Compose
- Python 3.12 com `uv` instalado
- (Opcional, para Modo 2) Tailscale instalado em cada PC, autenticado na mesma tailnet.
- (Opcional) GPU NVIDIA com `nvidia-container-toolkit`.

## Modo 1 — Dev local (single-host)

```bash
make dev               # sobe todos os serviços
make pull-models       # baixa qwen2.5:7b-instruct e nomic-embed-text
make smoke             # roda smoke ponta-a-ponta
make logs              # acompanha logs
make down              # derruba tudo
```

UIs:
- Gateway: http://localhost:8000/docs
- RabbitMQ: http://localhost:15672 (guest/guest)
- Qdrant: http://localhost:6333/dashboard
- Grafana: http://localhost:3000 (admin/admin)
- Prometheus: http://localhost:9090

## Modo 2 — Distribuído (3 PCs)

Pré-requisitos:
1. `tailscale up` em cada PC, copiar IPs para `infra/ansible/inventory.yml`.
2. SSH key do PC1 em `~/.ssh/authorized_keys` dos outros PCs.
3. Preencher `.env.distributed` com os IPs Tailscale.

```bash
bash scripts/deploy.sh        # bootstrap + deploy via Ansible
make smoke                    # smoke contra o gateway no PC1 via Tailscale
```
